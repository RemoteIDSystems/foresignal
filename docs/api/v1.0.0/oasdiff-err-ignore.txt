# What is not here: additive growth of a value list. Every list that grows as the server adds features is declared
# `x-extensible-enum` in docs/OpenAPI.json, which oasdiff treats as open, so a new value needs no entry. That includes

# NotificationWebhookMessage, whose list stays `enum` (oasdiff cannot mark a webhook payload extensible); oasdiff
# reports no error for its additions. Each entry below is a change oasdiff cannot be told is safe, with its reason.
