# foresignal_api (generated)

The Dart client for every operation in [`docs/OpenAPI.json`](../../../docs/OpenAPI.json), generated by
openapi-generator `dart-dio` with `serializationLibrary=json_serializable` from the OpenAPI 3.0.3 copy written by
`scripts/sdk/preprocess-dart.py`. **Everything in this package except this README, `pubspec.yaml`,
`analysis_options.yaml` and `.gitignore` is generated** (see `.openapi-generator-ignore`); regenerate with
`./gradlew generateSdks` instead of editing it. The streaming, paging and client-contract helpers live in the
hand-written sibling package [`foresignal_sdk`](../foresignal_sdk).

## Install

From a local checkout:

```yaml
dependencies:
  foresignal_api:
    path: ../foresignal/sdk/dart/foresignal_api
```

From git:

```yaml
dependencies:
  foresignal_api:
    git:
      url: https://gitlab.com/adam.allard/foresignal.git
      path: sdk/dart/foresignal_api
```

The `*.g.dart` parts are committed, so consumers do not run `build_runner`.

## Use

```dart
import 'package:dio/dio.dart';
import 'package:foresignal_api/foresignal_api.dart';

final api = ForesignalApi(dio: Dio(BaseOptions(baseUrl: 'https://foresignal.example.org')));
api.setBearerAuth('bearerToken', 'fs_…');
final records = await api.getRecordsApi().listRecords(kind: ['aircraft'], limit: 100);
```

Share the same `Dio` with `foresignal_sdk`'s `HttpTransport(dio: …)` to reuse connections and interceptors.

## Versioning and publishing

The package version is the API's `info.version` (`1.5.0`). Tool versions are pinned in
[`sdk/versions.properties`](../../versions.properties). Publishing is a separate release step; this package is
`publish_to: none`.

## Known generator limits

The preprocess step moves a few constructs dart-dio cannot compile to `x-foresignal-oas31-*` extensions: unions of
primitives become untyped (`Object?`) members, constraint-only `anyOf` blocks are not enforced client-side, enum
values containing an apostrophe are plain strings, and enum or list defaults are left to the server. The property
names `override` and `_type` are generated as `overrideValue` and `typeUnderscore`, and the enum value `index` as
`indexValue`.
