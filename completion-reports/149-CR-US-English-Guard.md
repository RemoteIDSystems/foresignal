## The guard

`checkUsEnglish` (`gradle/us-english.gradle.kts`, applied and wired into `check` in `build.gradle.kts` next to
`checkUnidataScope`) is a Kotlin task with no new runtime. It scans `src/main/**/*.java`, `src/test/**/*.java`
and `docs/*.md`. It does not reach `**/resources/**`, `docs/OpenAPI.json`, `docs/api/**` or `build/`, all of
which sit outside those trees. `grep` found no vendored or generated Java: `BundledCountryPolygons` says
"Generated by", but it is a 5 KB loader and is scanned.

- **Words.** `gradle/us-english/british-words.txt` lists every British form as families (`our`, `ise`, `yse`,
  `re`, `ce`, `ogue`, `ll`, explicit pairs). The task generates the inflections, 1,783 forms in all. There is no
  generic "-ise" rule, which would flag precise, promise and expertise. "analyses" is not flagged, because it is
  also the plural of "analysis". `grey` is a `lower` entry, so a standalone capitalized "Grey" (a surname) is
  skipped. Greyhound is not a listed form.
- **Matching.** Identifiers are split at camelCase, underscore and digit boundaries, and each word is matched
  whole. Every finding prints `file:line: word -> american [context]`, and the list is written to
  `build/reports/us-english/findings.txt`.
- **Context.** A small lexer labels each character as code, string literal, comment or Markdown prose. Javadoc
  `{@code}`, `{@link}` and `@param` names count as code, and so do Markdown code spans (even when wrapped across
  lines) and fences. A compound token (`licenceFiltered`, `favourites_count`) counts as code wherever it sits,
  since no sentence spells one.
- **Suppression.**
  - **Line marker:** `us-english: <reason>` (`<!-- … -->` in Markdown). A marker with no reason is itself a
    finding. No marker is in use.
  - **Allowlist file:** `gradle/us-english/allowlist.txt`, one entry per line: `<path glob> | <match> |
    [category] reason`. `<match>` is one of:
    - `code:` — the word as an identifier;
    - `string:` — inside the string literals of the named files;
    - `ident:` — an exact identifier;
    - `text:` — a line containing the text;
    - `word:` — any use (no entry uses this).
  - **Categories:** `wire`, `data`, `quote`, `license`, `vendored`, `foreign`, `proper-noun`. An unknown category,
    a missing reason or an entry that matches nothing fails the task. `--info` prints each entry's usage.

**Probe.** A throwaway `UsEnglishProbe.java` was added, run and deleted before the commit. Results:
- Flagged: "colour" in a comment and "greyed".
- Suppressed: `favouriteColour = "behaviour"` behind a reasoned marker.
- Failed as intended: a marker with no reason.
- Not flagged: "precise", "promise", "analyses", "Lady Grey", "Greyhound" and `"Earl Grey"`.

## Judgment calls

- **The licence identifiers are allowlisted, not renamed.**
  - The API spells it "licence" in 13 fields, the `LicenceTerms` and `ExportLicenceSummary` schemas, five DB
    columns, two headers, the `licencePolicy` parameter, two error codes, two egress reasons and two file names.
  - The Java record components and getters are those JSON keys, and the type names mirror them.
  - Renaming only the internal ones means auditing every rename for Jackson visibility. Only the contract tests
    this prompt forbids running could prove that audit right. So the prompt's bias applied: allowlist.
  - Prose "licence" in comments, docs, descriptions and messages was corrected.
- **Other internal identifiers were renamed, with wire values kept exactly.**
  - Renamed: `SeriesQueryService.Catalogue`, `Cursor.Kind.CATALOGUE` (the cursor encodes `"c"`, not the name),
    `AlertQualityService.MIN_LABELLED`, `BacktestJobEntity.cancelled`, `ExportJobEntity.CANCELLED`,
    `CalendarService.CANCELLED_DAYS`, `SignalFamilies.AIS_BEHAVIOUR`/`AVIATION_BEHAVIOUR`,
    `CapRecordMapper.STATE_CANCELLED`, `AisMessage.draught`, `quantise`, `neighbours`, `EmwinTextParser.cancelled()`,
    the local variables, and five test method names.
  - Values kept exactly: `@Column(name = "cancelled")`, `"CANCELLED"`, `"ais-behaviour"`, `"cancelled"` and
    `"draught"`. This follows the existing `ExerciseRunEntity.CANCELED = "CANCELLED"`.
  - `grep` found no direct serialization of `BacktestJobEntity`, and `EmwinTextParser.Warning.cancelled()` is not
    a bean getter.
- **The contract decided several strings.** These appear in `docs/OpenAPI.json` and were kept:
  - `IndexFitService.METHOD` ("L2-regularised …", the `IndexFitResult.method` default);
  - `CycleVocabulary`'s footer (the `Assessment.footer` default) and `AnalystRunner`'s (the `AnalystNote.footer`
    example);
  - `PopulationPackService.NOTE`; `standardisedZ`/`P`; `labelledShare`; `summarised`; `normalised`;
    `log-level-standardised`; `external-catalogue`; `data-centre`.
- **`ImpactProjector.LABEL`** ("modelled; heuristic links may be wrong …") is kept. It is stored in every
  projection's `labels`, and MCP clients are told to quote it verbatim.
- **`licences.json` entries are kept.** That is a published catalog (its "Unknown licence" entry and the inat,
  gdacs and ioda license values aliased in it). So are the `derived (input licences …)` values stored on fetch
  rows.
- **External text is kept:** Open Government Licence titles, the NLOD title and credit, Fintraffic's credit,
  BMRS Data Licence, publisher URLs, EMSC, a French OSM name, OSM `harbour`, Mastodon `favourites_count`, ERDDAP
  `analysed_sst`, AISStream `MaximumStaticDraught`, the tpw-data `organisations` directory, UK sanctions
  `organisation`, NAVAREA `METRE`, RFC 5545 `STATUS:CANCELLED`, and JTS's `Envelope.centre()`.
- **The three named fixes:**
  - `SubmarineCablesAdapter.java:29` now reads "stylized";
  - `SubmarineCablesAdapter.java:173` now reads "The map color";
  - `GpsjamAdapter.java:41` now reads "license".
- **A heading anchor followed.** Operator Guide "Licences and egress" became "Licenses and egress". Its one
  in-page link (`:3522`) and its quoted mention (`:6022`) were updated. `grep` found no other reference.
- **Two corrections were rolled back:**
  - The comment rewrite had turned 16 `@param licence` tags into `@param license` while the parameters are still
    `licence`. They were restored, and the guard now treats `@param` names as code.
  - `nwr/harbour=yes`, an OSM tag in an osmium command, was restored.
