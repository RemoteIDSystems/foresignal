## A — the global pull governor

`collect/PullGovernor.java` is a fair `Semaphore` subclass whose `reducePermits` is reachable, wrapped with
`acquire()` (returning an `AutoCloseable` `Permit` that releases once), `resize(int)`, `cap()`, `inUse()` and
`waiting()`.

- **Chokepoint.** `FetchExecutor.execute` calls the new private `pull(...)` where it used to call `run(...)`: after
  the overlap flag and the backoff check, immediately before the pull. The permit is held in try-with-resources, so
  it is released in `finally`. Scheduled and manual fetches both pass through here (`ManualFetchService` calls
  `executor.execute(id, MANUAL, allowShrink)`).
- **The wait is not the fetch.** The fetch timeout and duration start inside `run(...)`, so a fetch queued for a
  permit is not timed out by its wait. The overlap flag is held during the wait, so the scheduler cannot queue a
  second run of the same source behind the first.
- **Interrupted while waiting.** The run is skipped with the new reason `FetchOutcome.SKIP_INTERRUPTED`
  (`"interrupted"`), counted under `foresignal.fetch.skipped`, with no health change. The class javadoc's outcome
  table has a row for it.
- **Probes.** `ProbeService.probeCall` and `probePolling` wrap `dispatcher.call` in `gated(...)`. The streaming probe
  is not gated.
- **Backfill.** Not gated: `ChronicleBackfill` reads the database and makes no upstream pull.
- **Streams.** `StreamingSupervisor` does not reference the governor.
- **Unchanged.** Per-source threads, `CollectorScheduler.STAGGER`, `HostPacer` and `BudgetGovernor`.
- **Wiring.** `FetchExecutor` and `ProbeService` take the governor by optional setter injection, like
  `setUsageMeter`, so a hand-built executor in a test runs ungated.
- **Cold start.** There is no separate ramp. The pool is fair, so with N sources due, `cap` pull and the rest queue
  in arrival order.

## B — `maxConcurrentPulls`

- `settings/CollectorSettings` is a record `{maxConcurrentPulls}`: default 2, clamped to 1–16 in the canonical
  constructor, so a stored value cannot escape the range.
- `CollectorSettingsService` provides `get`, `update(JsonNode)` and a static `parse`. A value out of range is
  clamped. A non-integer, or an unknown member, is a 400 `VALIDATION_FAILED` with its field.
- `SettingKeys.COLLECTOR = "collector"` is added to `SettingKeys.ALL`.
- `CollectorSettingsController` serves `GET` and `PUT /v1/settings/collector` (`getCollectorSettings`,
  `updateCollectorSettings`, tag Settings). These are admin-only through `/v1/settings/**`.
- `PullGovernor.onSettingChanged` resizes on an `AppSettingChangedEvent` for `collector`. A larger cap releases
  permits at once. A smaller one reduces permits, which interrupts no running pull and admits no new pull until
  enough running ones finish.
- **OpenAPI.**
  - `info.version` is `1.2.0`, with a new 1.2.0 changelog entry at the top. The history is untouched.
  - Two paths are added: `/v1/settings/collector` and `/v1/sources/enable-core`.
  - Two schemas are added: `CollectorSettings` and `EnableCoreSourcesResult`.
  - The `enableFreeSources` description no longer says a fresh install seeds free sources enabled.
  - The frozen `docs/api/v1.0.0/OpenAPI.json` is untouched.
- **Version.** `build.gradle.kts` `version = "1.2.0"`; `ApiVersionTest.RELEASE = "1.2.0"`.
- **Postman.** Regenerated by `./gradlew generatePostman`, which printed
