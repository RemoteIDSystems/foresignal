THE THREE REPOSITORIES

Separation by design.

Only two components are essential to operate and control an instance. The example visualization is independent and optional.

01CORE

The Engine

foresignal

Headless intelligence core: collection, normalized history, analysis, alerts, forecasting, REST, geospatial data and MCP.

Primary productOpen repo
02CORE

The Control Plane

foresignal-admin

Native Flutter app for configuring sources, managing AI, validating ingest, tuning budgets, and monitoring a running instance.

Primary productOpen repo
03EXAMPLE

One Example Client

foresignal-client

React / Cesium web application demonstrating maps, investigations, forecasting, satellite workspaces, and analyst exploration.

Optional implementationOpen repo

Repository links can be configured in assets/js/site-config.js. The engine URL is prefilled from the project charter; Admin and Client URLs are left unset until confirmed.
