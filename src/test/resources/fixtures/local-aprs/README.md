# `local-aprs` fixtures

| File | What it is |
|---|---|
| `direwolf-kiss.hex` | **`synthetic: true`.** A KISS byte stream as a TNC serves it on its KISS TCP port, as hex pairs, one KISS frame per block after a `#` label: a position (not repeated), the real Mic-E packet `N8QH-9>SWSPQT,WA6TOW-2,WIDE1*,WIDE2-2` from `../aprs-is/stream-r-sf-bay.txt` (both digipeaters with the H bit set), a position-weather report, a status whose info field holds the bytes 0xC0 and 0xDB (escaped as `FESC TFEND` and `FESC TFESC`), a KISS command frame (TXDELAY, ignored), a UI frame on TNC port 1, a MeshCore KISS modem payload (not AX.25) and an AX.25 SABM (not UI) |

No TNC was reachable during the build, so the stream was generated by a short script that encodes AX.25 UI frames
(AX.25 2.2: shifted address characters, SSID byte with H and extension bits, control 0x03, PID 0xF0) and KISS
framing (FEND 0xC0, FESC 0xDB) exactly as the tests' `Ax25UiDecoder.encode` and `KissFrameDecoder.encode` do.

**Recapture** (prompt 143, on the operator's hardware): with Direwolf running `KISSPORT 8001`, record a few minutes of
what it serves, without sending it anything (`-d`: netcat never reads stdin, so it never half-closes the socket):

```sh
timeout 300 nc -d 192.168.1.20 8001 | xxd -p -c 32 > direwolf-kiss.hex
```
