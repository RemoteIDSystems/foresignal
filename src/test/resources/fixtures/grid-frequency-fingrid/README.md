# `grid-frequency-fingrid` fixtures

Synthetic: built by hand from Fingrid's documented dataset-177 shape (no key during construction); recapture with a
real key. The window starts in band, dips below the ±0.1 Hz Nordic operational band (49.91, 49.88 Hz) and returns.

URL: `https://data.fingrid.fi/api/datasets/177/data?startTime=…&endTime=…&pageSize=20000`, header `x-api-key`.
