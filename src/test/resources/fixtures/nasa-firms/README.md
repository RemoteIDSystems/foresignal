# `nasa-firms` fixtures

`synthetic: true` — **recapture with a real key** (a FIRMS MAP_KEY). No MAP_KEY was available when prompt 065
was built (2026-10-13), so `viirs.csv` and `modis.csv` were generated by a script, not captured. Their headers
follow the column names of the FIRMS attribute page
(<https://www.earthdata.nasa.gov/data/tools/firms/active-fire-data-attributes-modis-viirs>, read 2026-10-13) in
the order God's Eye View recorded from a live response on 2026-07-16 (`src/data/firmsCsv.js`); the parser finds
columns by name, so the order does not matter. Every row is dated 2026-10-13, with times from 00:05 to 11:31 UTC
and `acq_time` unpadded as FIRMS sends it.

| File | What it is |
|---|---|
| `viirs.csv` | 50 synthetic VIIRS NOAA-20 rows over the contiguous US (`bright_ti4`, `bright_ti5`, confidence `l`/`n`/`h` in rotation) |
| `modis.csv` | 50 synthetic MODIS rows over the contiguous US (`brightness`, `bright_t31`, numeric confidence; the first six rows are 0, 29, 30, 79, 80 and 100 for the class boundaries) |
| `invalid-key.txt` | Hand-made from the real answer to a dummy key: `Invalid MAP_KEY.` (HTTP 400, `text/plain;charset=UTF-8`, verified 2026-10-13 with a key of sixteen zeros) |
| `html-error.html` | Hand-made HTML error page |
| `header-only.csv` | The VIIRS header with no rows (zero detections, valid) |
| `unpadded-times.csv` | Three VIIRS rows with `acq_time` 5, 45 and 1305 (00:05, 00:45, 13:05) |
| `bad-coords.csv` | Seven VIIRS rows: two valid, and latitude 91, longitude −181, an empty latitude, `abc` and `NaN` (five skipped) |

**Capture procedure (prompt 143, with a `FORESIGNAL_VERIFY_*` MAP_KEY in `$KEY`):**

```sh
curl -s "https://firms.modaps.eosdis.nasa.gov/api/area/csv/$KEY/VIIRS_NOAA20_NRT/-125,24,-66,50/1" | head -n 51 > viirs.csv
curl -s "https://firms.modaps.eosdis.nasa.gov/api/area/csv/$KEY/MODIS_NRT/-125,24,-66,50/1" | head -n 51 > modis.csv
```

Each command costs one transaction (or more for a large answer). After capturing, check the live header against
the parser's columns (`FirmsCsvParser`), whether an `instrument` or `type` column is present, and whether the
`version` values are as above; then update `FirmsCsvParserTest` and `FirmsAdapterTest` to the captured times and
counts, and remove the `synthetic` line. Never commit the key.
